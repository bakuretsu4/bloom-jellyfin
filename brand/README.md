# Brand

The mark is a five-petal blossom in dusk colours (gold at the throat, through pink, to lavender)
with a play button in its centre, drawn with a dark outline. The petals sweep round like a pinwheel.

| File | Use |
|---|---|
| `bloom-icon.svg`, `png/bloom-icon-{16..1024}.png` | The app icon: the blossom on an indigo tile. Dock, launcher, window icon. |
| `bloom-mark.svg`, `png/bloom-mark-1024.png` | The blossom on its own, in colour. Sign-in card, loader, README. |
| `bloom-glyph.svg`, `png/bloom-glyph-512.png` | One colour (it takes the colour of whatever draws it): tray, monochrome places. The petals are separated by gaps and the play button is cut out. |
| `bloom-lockup.svg`, `png/bloom-lockup-1600.png` | The blossom with "Bloom" set in Fira Sans ExtraBold (as paths, so no font is needed). |
| `bloom-discord-1024.png` | The Discord application asset: the icon at 1024. Uploaded to Discord's developer portal by hand. |

Colours: outline `#2b2131`; petals `#ffb347` to `#ffc2d6` to `#d9c6ff`; centre `#ffd35e` to `#f08a2a`; tile
`#3a2a78` to `#1a1240` with a soft `#ffcf66` glow. The mark is detailed: below about 24 px use the glyph.

The previous mark (a moth in a viewfinder) is in git history. `concepts-v2/` holds the sketches this one
was chosen from (private; the public export leaves it out).
