# Bloom documentation

Guides for using Bloom, the Linux desktop client for Jellyfin.

- **[Getting started](getting-started.md):** installing, connecting to your server, signing in,
  several servers and accounts, updating and uninstalling.
- **[Watching](watching.md):** the player, quality, audio and subtitles, skipping intros, up next,
  hardware decoding, trailers and Discord.
- **[Downloads and offline](downloads.md):** saving films and episodes, quality, where they go,
  and watching without a server.
- **[Settings](settings.md):** every option, what it does and its default.
- **[Custom themes](themes.md):** making your own colours and font, and sharing a theme.
- **[Troubleshooting and FAQ](troubleshooting.md):** playback on the CPU, hybrid laptops, servers
  that don't show up, Discord, logs, and starting fresh.

Want to help build Bloom? See [CONTRIBUTING.md](../CONTRIBUTING.md).
